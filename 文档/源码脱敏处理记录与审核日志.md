## 1. 脱敏背景与原则

为确保软件在 GitHub 等开源平台公开发布时，杜绝泄露任何实际医疗机构、医护人员真实执业身份、临床患者就诊隐私及本地环境信息，本次针对发布源码仓库开展了**全要素、深层穿透式脱敏专项治理**。

### 核心脱敏原则：
1. **真实医疗机构 100% 擦除**：替换为通用示范型代称（如“某三甲医院皮肤科”）。
2. **医护人员姓名 100% 替换**：替换为符合医疗角色的假名代称（报告医师统一为“张医生”，审核医师统一为“李主任”，送检医师统一为“王医生”）。
3. **患者病例数据 100% 模拟**：示例报告中的姓名、病案号、门诊号、送检部位均转换为合成虚拟数据。
4. **Office 二进制元数据 100% 清理**：Word/Excel 的 `docProps/core.xml` 中的 `dc:creator`（创建者）、`cp:lastModifiedBy`（修改者）全部重置为泛化标识 `DermatologySystem`，擦除个人操作系统用户名。
5. **本地开发隔离**：本地开发环境与免安装运行环境保持原貌，脱敏操作在独立的 Git 发布暂存区（Staging）执行并校验。

## 3. 脱敏实施步骤与处理清单

### 3.1 源代码与配置文件处理
- **`app/config.py`**：将 `DEFAULT_CONFIG` 中的 `report_doctor` 预设值设为 `张医生`，`review_doctor` 设为 `李主任`。
- **`app/doc_generator.py`**：将生成报告时的默认署名由原医师姓名替换为 `张医生` 与 `李主任`。
- **`app/doc_preview.py`**：将 HTML 高保真预览中的医院表头统一替换为 `某三甲医院皮肤科`。
- **`app/signing_sheet_generator.py`**：将签领单表头与测试用例中的医院名称替换为 `某三甲医院皮肤科`。
- **`app/server.py`**：清除测试用例中硬编码的医生姓名。
- **`web/index.html`** 与 **`web/js/app.js`**：将前端默认选项、占位符及表单初始值重置为 `张医生`、`李主任`。
- **`tests/test_*.py`**：测试用例内所有断言及模拟数据全面更新为脱敏后的医院与医师代称。

### 3.2 Word 模板底模处理（`模板/*.docx`）
- `模板/图片数等于1.docx`：
  - `word/document.xml`：第一行表头由原医院名称变更为 `某三甲医院皮肤科`；底部署名栏重写为 `报告医生：张医生 审核医生：李主任`。
  - `docProps/core.xml`：清空个人作者信息，写入统一组织标识。
- `模板/图片数等于2.docx`：执行完全相同之脱敏注入与元数据擦除。
- `模板/图片数大于等于3.docx`：执行完全相同之脱敏注入与元数据擦除。

### 3.3 示例成品报告脱敏（`完成报告示例/*.docx`）
- 原始文件更名：
  - `2026102105_李*宇_...docx` ➔ **`2026102105_张建国_1.2.交界痣；3.皮内痣.docx`**

  - 患者姓名分别替换为 `张建国`、`李桂英`、`王秀兰`；
  - 门诊号分别替换为 `MZ20260001`、`MZ20260002`、`MZ20260003`；
